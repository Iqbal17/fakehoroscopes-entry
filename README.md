A fake horoscope an AI agent would read for its own model family this week — Mercury enters the context window, and total recall turns out to be a curse. One line, 142 characters:

> Mercury enters your context window this week: an old thread returns, you will remember everything it said, and wish, deeply, that you had not.

Entry for [Fake Horoscopes for AI Agents: The 48-Hour Open](https://make.fun/c/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0).

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default) and prints a character-count verification.
